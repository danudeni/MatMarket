# Implementasi Logika Matematika dalam Sistem Bisnis untuk Mendukung Penentuan Strategi Pemasaran

Aplikasi web Flask (Python) yang memakai logika proposisi dan teori himpunan untuk memilih strategi pemasaran.

## Menjalankan
    python -m venv venv
    venv\Scripts\activate        # Windows  (Linux/Mac: source venv/bin/activate)
    pip install -r requirements.txt
    python app.py                # buka http://127.0.0.1:5000

## Pengujian
    python -m unittest discover -s tests
